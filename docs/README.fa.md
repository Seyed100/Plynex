# پلینکس — Plynex

مدیاپلیر متن‌باز برای ویندوز و لینوکس با Rust، Tauri 2 و موتور mpv. رابط مینیمال با تم روشن و تیره، پالت خنثی گرم، آیکون‌های Phosphor و فونت‌های Manrope و وزیرمتن طراحی شده است.

## دریافت و نصب

فایل‌ها را از [بخش انتشار](https://github.com/Seyed100/Plynex/releases) دریافت کنید. راهنمای کامل در [INSTALL.md](INSTALL.md) است.

- **ویندوز ۱۰/۱۱، ۶۴ بیت:** فایل Setup را اجرا کنید یا ZIP پرتابل را کامل استخراج کنید. در اولین اجرای برنامه، موتور mpv از منبع اصلی دریافت و هش آن بررسی می‌شود؛ این مرحله اینترنت می‌خواهد. بعد از آن پخش محلی آفلاین است. WebView2 نیز باید نصب باشد.
- **اوبونتو/دبیان:** بسته DEB را با دستور زیر نصب کنید؛ وابستگی mpv خودکار نصب می‌شود.

```bash
sudo apt install ./Plynex_0.2.0_amd64.deb
```

- **AppImage:** ابتدا mpv را نصب کنید و به فایل AppImage مجوز اجرا بدهید. این بسته موتور mpv را داخل خودش ندارد.
- **RPM:** وجود mpv و WebKitGTK مناسب در مخازن توزیع لازم است. آزمون اجرای فدورا هنوز محدود است.

لینوکس فعلاً به X11 یا XWayland و یک compositor نیاز دارد. فایل‌های نصب امضای دیجیتال ندارند؛ هش SHA-256 فایل را با SHA256SUMS.txt همان انتشار مقایسه کنید.

## امکانات

پخش ویدیو و صدا با فرمت‌های پشتیبانی‌شده توسط mpv/FFmpeg، صدا تا ۱۵۰٪، سرعت ۰٫۲۵ تا ۴ برابر، زیرنویس داخلی و خارجی، تنظیم تأخیر صدا/زیرنویس و اندازه نوشته، پلی‌لیست و جستجو، فصل‌ها، ادامه پخش، اسکرین‌شات، تمام‌صفحه و پنجره قابل تغییر اندازه.

Space یا K برای پخش/توقف؛ چپ و راست برای جابه‌جایی ۵ ثانیه؛ Shift همراه آن‌ها برای یک دقیقه؛ بالا/پایین برای صدا؛ M برای بی‌صدا؛ F برای تمام‌صفحه؛ Ctrl+O برای بازکردن فایل و Ctrl+Shift+O برای زیرنویس.

نسخه اول عمومی 0.2.0 است. پوشش همه کدک‌ها، همه سخت‌افزارها یا فایل‌های خراب و DRM تضمین نمی‌شود. رابط برنامه فعلاً انگلیسی است؛ ترجمه کامل فارسی و RTL در برنامه توسعه قرار دارند.

## توسعه و مشارکت

Node.js 22، Rust پایدار و پیش‌نیازهای Tauri را نصب کنید:

```bash
git clone https://github.com/Seyed100/Plynex.git
cd Plynex
npm ci
npm run desktop
# ساخت فایل نصب
npm run package
```

[راهنمای مشارکت](../CONTRIBUTING.md)، [معماری](ARCHITECTURE.md)، [تست‌ها](TESTING.md) و [پیشنهادهای توسعه](ROADMAP.md) توضیحات کامل دارند. پیشنهادهای مهم شامل پشتیبانی بومی Wayland، تست گسترده GPU و 4K، انتشار امضاشده، ترجمه فارسی، کنترل‌های رسانه سیستم و پیش‌نمایش نوار زمان است.
